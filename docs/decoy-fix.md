# Разбор: Чучело не забирало шпионов соперника

## Симптом

Игрок кладёт шпиона соперника себе на стол (шпион приходит из колоды соперника и
после розыгрыша принадлежит уже вам). Чучело в руке подсвечивает ряд, но шпион
остаётся недоступен: тап по нему ничего не делает.

## Причина

В `UI.selectCard` стояло условие:

```js
if (!card.isUnit() || card.holder !== pCard.holder || card.abilities.includes("spy"))
    return;
```

и такое же исключение в `UI.setSelectable`:

```js
let units = r.cards.filter(c => c.isUnit() && c.holder === card.holder && !c.abilities.includes("spy"));
```

Третье место — обработчик тапа в `portrait.js`, где повторялась та же проверка.

Шпион — обычная карта отряда (не герой), и после розыгрыша `holder` уже указывает на
вас, поэтому проверка владельца его пропускает. Ложным было именно исключение по
способности `spy`, добавленное «на всякий случай». В Ведьмак 3 Чучело не различает
способности цели — важен только тип карты и сторона стола.

## Исправление

1. `www/rules.js` — единственный источник истины:
   `isDecoyTarget(card, holder, rowIndex, sideStart)` проверяет сторону, тип карты
   (не герой) и владельца; `decoyTargets`, `decoyRows`, `hasDecoyTarget` построены на нём.
2. `UI.selectCard` — ищет ряд цели и спрашивает правило.
3. `UI.setSelectable` — подсвечивает ряд и снимает `noclick` со всех законных целей,
   включая шпионов.
4. `portrait.js` — тап по карте проверяет то же правило и не подставляет «первую
   попавшуюся» карту ряда.
5. `UI.resolveDecoy` — общий обмен для игрока и ИИ: цель в руку владельца, Чучело на
   её место. ИИ больше не использует `setTimeout` и не теряет карту в гонке.
6. Если цели нет, `showPreview` и `playCard` показывают подсказку, а ход не тратится.

## Тесты

`tests/decoy.test.mjs`:

- шпион соперника на вашей стороне — законная цель, возвращается в руку;
- герой — не цель, ход не тратится;
- карта на стороне соперника — не цель;
- несколько целей в разных рядах — работает выбор ряда.

`tests/decoy-flow.test.mjs`:

- ИИ забирает перевёрнутого шпиона, а не оставляет его на столе;
- ИИ не тратит Чучело, если на столе только герои;
- подсказка при отсутствии цели.
## Версия 1.3.0: сторона вместо владельца

Проверка «владелец совпадает» оказалась недостаточной: у шпиона `holder` меняется
асинхронно, и в момент обмена он мог ещё указывать на соперника. Теперь
`GwentRules.isDecoyTarget` смотрит только на **сторону стола** и тип карты, а
`UI.resolveDecoy` явно передаёт владение тому, кто разыграл Чучело:

```js
const holder = decoy.holder;
target.holder = holder;
await board.toHand(target, row);
await board.moveTo(decoy, row, holder.hand);
```

Плюс `ability_dict.spy.placed` сначала добирает карты и меняет владельца, и только
потом проигрывает анимацию — обмен во время анимации больше не «переворачивает»
карту обратно. Тест: `tests/decoy.test.mjs` («stale opponent holder») и
`tests/decoy-flow.test.mjs`.
