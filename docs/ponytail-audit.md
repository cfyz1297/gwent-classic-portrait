# Ponytail-аудит проекта (режим full)

Проверка по лестнице решений Ponytail: «нужно ли это вообще → есть ли в проекте →
стандартная библиотека → нативная возможность → уже установленная зависимость →
одна строка → минимальная реализация». Безопасность, валидация и тесты не
сокращались.

## Что исправлено

| Находка | Решение |
|---------|---------|
| Класс `AudioCycle` (20 строк) нигде не использовался | удалён |
| Метод `CardContainer.getCardsRandom` не вызывался | удалён |
| 9 иконок `card_special_*` и `card_weather_*` (~240 КБ) не упоминались ни в JS, ни в CSS, ни в HTML | удалены |
| `www/README.md` (документация upstream) попадал в APK | перенесён в `docs/upstream-www-readme.md` |
| `eventManager` выглядел мёртвым, но конструктор `EventManager` создаёт статические события | оставлен, добавлен комментарий-объяснение |
| Подписи уведомлений были английскими строками в CSS | переведены на русский (17 строк) |
| Баннер конца игры тайлился: у элемента не было `background-repeat: no-repeat` | исправлено, пропорции 656/416 |
| Дублирующиеся правила `#passed-op` / `#passed-me` | сведены в одно |

## Что оставлено сознательно

- **Легаси-ландшафт в `style.css`** (~1.5 тыс. строк). Портретный слой
  перекрывает его, но безопасно вырезать можно только с визуальной регрессией на
  всех экранах. Это долг, а не мусор: `ponytail:debt` — отдельная задача с
  прогоном скриншотов.
- **`sharp` в devDependencies** — нужен только одноразовому
  `scripts/import-ru-cards.mjs`; в рантайм и CI-сборку APK не попадает.
- **Динамические имена ассетов** (`iconURL("power_" + ability)`) не позволяют
  безопасно удалять картинки статическим поиском; скрипт аудита помечает их как
  «неиспользуемые» ложно.
- **Явный список тестов в `package.json`** — переносимость между Node 20/24 и
  Windows/Linux; глоб-паттерн уже ломал CI.
- **`android/`** — сгенерированный каркас Capacitor, руками не чистим.
