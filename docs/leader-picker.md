# Выбор лидера фракции

## Что было

`DeckMaker.selectLeader` открывал общую карусель карт: пять лидеров листались
горизонтально, подписи брались из английских данных, описания способностей
показывались только в общем окне описания. На телефоне карусель перекрывала док,
а пассивные способности никак не отличались от активных.

## Что стало

`www/leader-picker.js` + стили в `www/portrait.css`:

- полноэкранная панель `#leader-picker` с `role="dialog"`, `aria-modal="true"`;
- список `role="radiogroup"`: каждый лидер — кнопка `role="radio"` с `aria-checked`;
- портрет, русское имя из `RU.cards`, описание из `RU.abilities`, метка
  «Активная способность» / «Пассивная способность»;
- текущий лидер подсвечен и получает фокус при открытии;
- выбор применяется сразу: `DeckMaker.setLeader`, `#leader-name-ru`, сохранение
  через `Settings.getFactionSettings(faction).setLeader`;
- закрытие: кнопка, тап по фону, Esc; фокус возвращается на кнопку-открывашку;
- клавиши ↑/↓/Home/End двигают фокус по списку;
- кнопка «Выбрать лидера» под портретом в редакторе колоды.

## Почему не карусель

Карусель — общий механизм для смены карт в руке, медика и просмотра сброса. У неё
нет места под длинные описания, она блокирует док и не даёт списка целиком. Для
выбора из пяти вариантов список с прокруткой удобнее и доступнее.

## Тесты

`tests/leader-picker.test.mjs`: открытие, количество вариантов, русские подписи и
метки, сохранение выбора, повторное открытие, Скеллиге (два лидера, Бран пассивный),
Esc и возврат фокуса.
