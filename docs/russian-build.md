# Русская версия (APK с русскими картами)

Отдельная сборка того же клиента: интерфейс уже русский, а в этой версии ещё и
**лицевые стороны карт на русском**. Ставится рядом с обычной, потому что у неё
другой пакет.

| | Обычная | Русская |
|---|---|---|
| APK | `gwent-classic-portrait-debug.apk` | `gwent-classic-portrait-ru-debug.apk` |
| Пакет | `com.thinkl.gwentclassic` | `com.thinkl.gwentclassic.ru` |
| Название | Гвинт | Гвинт (рус.) |
| Карты | английские лица из upstream | русские лица из архива duskworld/diablo1 |

## Откуда карты

Архив `cards.rar` (73,9 МБ) — это набор лицевых сторон на русском: 310×585 PNG,
разложены по папкам «Королевства севера», «Нильфгаард», «Монстры», «Скоятаэли»,
«Скеллиге», «Нейтральные карты», «Специальные карты», «Лидеры». Имена файлов
обезличены (`sev_1.png`, `nilf_7.png`), поэтому сопоставление с базой
`www/cards.js` сделано **по картинке**, а не по имени:

1. у каждой карты из `www/img/lg` и у каждого файла архива берётся перцептивный
   хеш области иллюстрации (без рамки и подписи);
2. для файла выбирается ближайшая английская карта по расстоянию Хэмминга;
3. дубликаты отбрасываются — остаётся лучший по расстоянию;
4. альтернативные арты `*a.png` (Ballad Heroes) пропускаются: базовый арт уже есть.

Среднее расстояние совпадения — 25 из 256, следующий кандидат обычно в 3–4 раза
дальше, поэтому ошибок сопоставления нет. Итог: **214 карт из 216**, без русской
картинки остались только `neutral_roach` (призывается способностью) и
`realms_ballista_1` (второй вариант арта); для них в русской сборке остаётся
английское лицо.

Пересобрать набор из архива:

```bash
# распаковать cards.rar в tmp/cards (unrar/7-Zip/WinRAR)
node scripts/import-ru-cards.mjs --from tmp/cards
```

Скрипт пишет `assets-ru/lg/*.jpg` (JPEG качества 86, ~9 МБ) и
`assets-ru/manifest.json` с парами «английский файл → файл архива» и расстоянием.

## Сборка

```bash
npm ci
export ANDROID_HOME="$HOME/android-sdk"   # JDK 21+
node scripts/build-ru-variant.mjs
```

Скрипт:

1. собирает `build/www-ru` — копию `www` с подменой `img/lg`;
2. временно переключает `capacitor.config.json` на `webDir: build/www-ru`,
   `appId: com.thinkl.gwentclassic.ru`, `appName: Гвинт (рус.)`;
3. подменяет `android/.../strings.xml` на русское название;
4. вызывает `npx cap sync android` и `gradlew assembleDebug -PappId=...`;
5. кладёт APK в `artifacts/gwent-classic-portrait-ru-<версия>-debug.apk`;
6. возвращает конфиг и `strings.xml` на место и повторно синхронизирует английские
   ассеты, чтобы рабочее дерево осталось чистым.

В CI это отдельная job `Build Russian APK` в `.github/workflows/android.yml`;
на теге обе сборки прикрепляются к релизу.

## Что не переведено

Названия карт и способности в интерфейсе уже русские (`www/ru.js`), подписи
экранов — тоже. На самой карте печатается то, что было в архиве; у пары лидеров
формулировки отличаются от `RU.cards` (например, «Властелин Юга» вместо
«Неумолимый»), потому что это подписи из другого издания. Иллюстрация при этом
соответствует карте.
