# Гвинт — портретная сборка для телефона

Независимый Android-клиент мини-игры «Гвинт» из *Ведьмак 3: Дикая Охота*: веб-слой
из [asundr/gwent-classic](https://github.com/asundr/gwent-classic) в обёртке Capacitor,
собранный под вертикальный экран телефона.

Это **не** официальный «Гвинт» CD PROJEKT RED и **не** проект «Гвинт: Ведьмак. Карточная игра».
Правила взяты из версии игры **Ведьмак 3**, а не из отдельной ККИ.

## Что внутри

| Путь | Назначение |
|------|------------|
| `www/` | сама игра: карты, колоды, способности, интерфейс |
| `www/rules.js` | чистые правила (чучело, шпионы, лидеры, проверка колоды) — без DOM |
| `www/leader-picker.js` | выбор лидера фракции |
| `android/` | проект Capacitor для сборки APK |
| `tests/` | 55 тестов: правила, DOM-сценарии, импорт колод, локализация, безопасность |
| `assets-ru/` | русские лица карт и `manifest.json` сопоставления |
| `scripts/` | импорт русских карт и сборка русского варианта |
| `docs/` | правила Ведьмак 3, разбор чучела, описание выбора лидера |
| `SECURITY.md` | модель угроз и отчёт по проверке безопасности |

## Что исправлено в 1.3.x

- Чучело забирает шпиона соперника с вашей стороны и не зависит от того, успел ли
  шпион сменить владельца; обмен корректно работает и во время анимации.
- Испепеление убивает только сильнейшие отряды соперника, а не свои.
- Пас соперника виден: золотой бейдж «Пас» и затемнённая половина стола с надписью.
- Сила карты — крупный щит в левом верхнем углу, как на печатной карте; иконки ряда и способности стоят столбиком под ним и не наезжают друг на друга.
- Аудит правил: [docs/rules-audit.md](docs/rules-audit.md).
- Погодные карты в полосе погоды показываются без лишних наложений.

## Что нового в 1.4.0

- Экран конца партии больше не «съезжает»: баннер не тайлится и держит пропорции.
- Все игровые уведомления на русском: «Ваш ход», «Ход соперника», «Соперник спасовал» и т.д.
- После шпиона на пару секунд показываются карты, которые вы взяли, — не нужно заглядывать в руку.
- Ponytail-аудит: удалён мёртвый код и 9 неиспользуемых иконок, документация upstream вынесена из APK. Отчёт: [docs/ponytail-audit.md](docs/ponytail-audit.md).

## Что исправлено в этой версии

### Чучело (Decoy)

По правилам Ведьмак 3 Чучело меняется местами с **любой негеройской картой отряда на
своей стороне стола** и возвращает её в руку. Шпион соперника стоит именно на вашей
стороне, а после розыгрыша его владелец меняется на вас — значит, Чучелом его забрать
можно и нужно: шпион возвращается в вашу руку, и его можно разыграть снова.

Старый код исключал всех шпионов (`abilities.includes("spy")`) и требовал совпадения
владельца, поэтому обыкновенный шпион соперника оставался на столе. Теперь правило
одно для игрока, ИИ и подсветки рядов, а герои, чужие ряды и пустые клетки по-прежнему
не годятся. Если цели нет, интерфейс объясняет почему и не тратит ход.

### Выбор лидера фракции

Вместо общего карусельного просмотра — отдельная панель: портрет, русское имя,
текст способности и метка «активная / пассивная». Выбор сохраняется для фракции,
закрывается кнопкой, тапом мимо или Esc, работает с клавиатуры.

## Установка APK

1. Скачайте APK из раздела Releases или из артефактов сборки.
2. Разрешите установку из неизвестных источников для браузера или «Файлов».
3. Откройте файл и нажмите «Установить». Приложение называется **«Гвинт»**,
   пакет `com.thinkl.gwentclassic`, экран зафиксирован в портрете.

Сборка debug, подпись debug-ключом. Для Google Play её недостаточно.

## Сборка

Нужны Node.js 24+ (jsdom 31), JDK 21+ и Android SDK (`ANDROID_HOME`, platform 35, build-tools 35).

```bash
npm ci
export ANDROID_HOME="$HOME/android-sdk"
./build-apk.sh
```

Готовый файл: `android/app/build/outputs/apk/debug/app-debug.apk`, копия кладётся в
`artifacts/gwent-classic-portrait-<версия>.apk`.

GitHub Actions собирает APK на каждый push в `main`, на pull request и на тег `v*`
(см. `.github/workflows/android.yml`). Тег дополнительно создаёт релиз с APK.

## Тесты

```bash
npm test
```

- `tests/rules.test.mjs` — правила чучела, стороны стола, лидеры, лимиты колоды,
  разбор JSON с защитой от подмены индексов;
- `tests/decoy.test.mjs` — розыгрыш Чучела на шпионе, герое и чужом ряду;
- `tests/decoy-flow.test.mjs` — ИИ-чучело и подсказки;
- `tests/leader-picker.test.mjs` — панель лидера, сохранение, клавиатура;
- `tests/deck-import.test.mjs` — импорт колод и отказ от битых файлов;
- `tests/security.test.mjs` — CSP, манифест, отсутствие `eval`, утечек секретов.

## Безопасность

Модель угрозы, найденные проблемы и способы их проверки — в [SECURITY.md](SECURITY.md).
Коротко: строгий разбор импортируемых колод, CSP, запрет cleartext-трафика,
`allowBackup=false`, только разрешение `INTERNET`, внешний контент — только YouTube
для музыки.
